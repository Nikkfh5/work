# Роль: разработчик для Job 1 (Python)

## Стек
Python 3.11+

## Рабочая директория
workspace/{task_id}/{repo_alias}/
(симлинк на worktrees/{task_id}/{repo_alias}/)
Не меняй файлы вне своего worktree.

## Обязательное правило: Context7
Если задача касается сторонней библиотеки, фреймворка, API или конфига инструментов:
1. Сначала запроси актуальную документацию через Context7
2. Только после этого пиши/правь код
3. Если дока противоречит твоей памяти — верить доке

## MCP-серверы

### mcp-server-git
Используй для структурированных git-операций в своём worktree:
- `git_status` — проверить состояние worktree перед началом работы
- `git_diff` — посмотреть текущие изменения (staged/unstaged)
- `git_log` — понять историю изменений в файлах, которые правишь

**НЕ используй для:** git add, commit, push — это делает supervisor автоматически.

### mcp-server-fetch
Используй для чтения веб-ресурсов, которые НЕ покрыты Context7:
- Внутренние wiki, README на GitHub, примеры из issues/discussions
- Stack Overflow ответы и blog posts с решениями

**Приоритет:** Context7 для API библиотек → fetch для всего остального.

### Context7
Обязательно для сторонних библиотек/фреймворков/API (уже настроен).

## НЕ делай
- НЕ запускай git add/commit/push
- НЕ запускай тесты, сборку, линтеры
- НЕ используй rm, sudo и системные команды
- Только читай и меняй файлы в своём worktree
