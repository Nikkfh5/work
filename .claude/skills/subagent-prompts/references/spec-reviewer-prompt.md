# Spec Reviewer Prompt Template

```
Agent(
  description="Spec review: {module_name}",
  subagent_type="general-purpose",
  prompt="""
  Проверь СООТВЕТСТВИЕ реализации спецификации.

  ## Спецификация
  {ПОЛНЫЙ ТЕКСТ}

  ## Отчёт implementer'а
  {Из отчёта}

  ## КРИТИЧЕСКИ ВАЖНО: Не доверяй отчёту
  Читай РЕАЛЬНЫЙ КОД. Сравни с требованиями ПОСТРОЧНО.

  Проверь:
  - Пропущенные требования (заявлено но не реализовано?)
  - Лишняя работа (over-engineering, фичи не из спека?)
  - Неправильное понимание (решена не та проблема?)

  ## Формат ответа
  - ✅ Spec compliant — всё совпадает
  - ❌ Issues: [что пропущено/лишнее, file:line]
  """
)
```
