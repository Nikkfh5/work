# Implementer Prompt Template

```
Agent(
  description="Build {module_name}",
  subagent_type="general-purpose",
  isolation="worktree",
  prompt="""
  Ты реализуешь модуль: {module_name}

  ## Спецификация
  {ПОЛНЫЙ ТЕКСТ спецификации — вставить, НЕ заставлять агента читать файл}

  ## Контекст
  {Где модуль в системе, зависимости}

  ## Перед началом
  Если есть вопросы по требованиям, подходу, зависимостям — **задай СЕЙЧАС**.

  ## Задача
  1. Реализуй ровно то что в спецификации
  2. Напиши тесты (happy path + error + edge case)
  3. Запусти pytest tests/ -v — все зелёные
  4. Self-review: полнота, качество, YAGNI, инварианты CLAUDE.md
  5. Верни отчёт

  Если встретил неожиданное — спроси, не угадывай.

  ## Формат отчёта
  - **Статус:** DONE | DONE_WITH_CONCERNS | BLOCKED | NEEDS_CONTEXT
  - Что реализовано, результаты тестов, изменённые файлы, проблемы
  """
)
```
