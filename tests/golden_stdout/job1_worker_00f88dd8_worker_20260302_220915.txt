Всё готово. Система создана в `workspace/`.

**Что сделано:**

- `workspace/app.py` — Flask-сервер с безопасным sandbox для выполнения кода пользователя (AST-проверка + whitelist буилтинов)
- `workspace/templates/index.html` — красивый тёмный UI с боковой панелью
- `workspace/static/js/app.js` — полная 3D-логика на Three.js
- `workspace/requirements.txt` — зависимости

**Функционал:**
- Загрузка Python-кода с функцией `get_trajectory()` → 3D-анимация дрона
- 5 встроенных примеров: прямая, круг, спираль, восьмёрка, Лиссажу
- Препятствия 4 типов: куб, сфера, стена, цилиндр (позиция, размер, цвет)
- Обнаружение столкновений (AABB + сфера) с красной вспышкой
- Управление скоростью, масштабом, следом траектории
- 5 режимов камеры (свободная, за дроном, сверху, сбоку, спереди)
- Телеметрия в реальном времени (X/Y/Z, скорость, дистанция)
- HUD с FPS

**Запуск:**
```bash
pip install flask flask-cors
python workspace/app.py
# http://localhost:5000
```
